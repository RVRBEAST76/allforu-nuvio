# AllForU Nuvio Scrapers

Local scrapers for the Nuvio app (same backends as AllForU CloudStream plugins).

## Install

1. Open Nuvio app
2. Settings → Local Scrapers
3. Add:
```
https://raw.githubusercontent.com/RVRBEAST76/allforu-nuvio/main/
```
4. Enable scrapers!
